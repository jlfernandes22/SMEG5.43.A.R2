# Risk, warranty and liability notice

## Experimental status

This repository is an independent reverse-engineering and emulation research project. It is not a manufacturer-approved update, production-ready vehicle modification, professional installation service or guaranteed recovery solution. Publishing source code, test results or instructions does not certify a particular head unit, firmware revision, vehicle or installation method.

The project includes code that can erase or rewrite internal flash, modify configuration, execute native maintenance modules and reset a head unit. Incorrect use, software defects, incompatible hardware, worn flash or interrupted power can leave an SMEG unit unusable, including permanently bricked. Loss of settings, data and functions, and the need for professional repair or replacement, are possible. Emulator success, matching CRCs and an installation-success message do not establish safe physical operation or recoverability.

Read the [deployment limits](docs/DEPLOYMENT.md) and [physical test report](docs/PHYSICAL_TEST_REPORT.md). The documented vehicle eventually booted with additional themes after an extended shutdown, but it had first remained on the Peugeot logo. That report is not a guarantee for another unit, and no fixed waiting period or universal recovery procedure has been established.
