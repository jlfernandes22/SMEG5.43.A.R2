# Emulator screenshots

These are unaltered copies of framebuffer contact sheets from local QEMU runs.
They contain generic FM screens, with no visible personal data or host labels.
Neither PNG contains text or EXIF metadata chunks.

| File | Original evidence path | Coverage |

The screenshots show emulator rendering, including known layout overlaps. They
do not establish physical head-unit compatibility, successful vehicle installation,
or complete graphics, radio and vehicle hardware emulation. Firmware UI artwork
shown here retains its original ownership; source-code licenses do not license it.
